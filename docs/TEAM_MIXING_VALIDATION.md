# 새로운 만남을 늘리는 팀 편성 보정

> 2026-09-07 · 로컬 코드 반영·검증 완료, 앱 배포 전. 당일 세션 안의 같은 경기 4명(파트너·상대 포함)을 ‘만남’으로 정의한다.

> 아래 새 만남 보너스 도입 실험은 **당시의 예약 1명 제한**을 양쪽에 적용한 결과다. 이후 운영진 자동편성의 1명 제한을 제거했다. 현재 정책은 대기 1명 이상을 확보하고 여러 명을 예약하며, 별도의 [예약 인원 제한 해제 검증](TEAM_RESERVATION_VALIDATION.md)에서 비교한다.

기존 그룹 반복 벌점에 **아직 만나지 못한 사람과의 새 만남 보너스**를 더했다. 첫 선발부터 현재 후보들 중 만난 사람의 폭이 좁은 참가자를 우대한다. 추천·자동편성·회원 파티가 같은 함수를 사용하며, 판수·대기·실력·유형·성별·경기 중 비용은 계속 합산한다.

## 적용 공식

`W_NEW_ENCOUNTER=12`. 완료 경기의 4인 집합과 현재 진행 중인 경기에서 ‘두 사람이 만났는가’를 파생한다. 같은 쌍을 여러 번 기록해도 동반 여부는 한 번만 센다. 진행 중인 경기를 완료 이력 벌점에 미리 더하지는 않는다.

```text
이미 선택한 멤버가 있을 때:
  새 만남 비용 = -12 × 후보가 아직 못 만난 선택 멤버 수

아직 선택한 멤버가 없을 때:
  새 만남 비용 = -12 × (현재 다른 후보 중 못 만난 인원 / 현재 다른 후보 수)
  다른 후보가 없으면 0
```

첫 선발의 보너스는 최대 12점, 이후 한 후보의 보너스는 최대 36점이다. 자동편성은 경기 중 인원 상한으로 선발할 수 없는 후보를 제외한 뒤 첫 선발의 비율을 계산한다. 후보마다 전체 과거 인맥 수를 비교하지 않으므로 지금 없는 상대가 분모를 부풀리지 않는다.

후보 추가로 만드는 새로운 두 사람의 연결이 U개라면 해당 보너스는 `-12U`다. 한 경기의 4명을 순서대로 선택할 때 2~4번째 선택에서 새 연결은 중복 없이 세어지고, 최대 6개다. 첫 선택의 비율 보너스는 별도의 시작점 선택 기준이다. **모든 비용을 합산해 한 명씩 고르는 방식이므로 전체 일정의 최대 만남 수를 보장하는 최적화는 아니다.**

새 만남 항은 유한하지만 기존 이력·대기 비용과 함께 순위를 정한다. ‘판수가 적은 사람보다 절대 먼저 나가지 않는다’는 제약은 아니다. 늦참 평균 보정의 수학적 의미는 [별도 검증](TEAM_MATCHING_MATH.md)을 참고한다.

## 비교 방법

- 실제 `autoFillTeammates`·`recommendTeammates`·`pairPlayers`를 호출한다. 점수 공식을 별도로 구현하지 않았다.
- 합성 로스터 6종, 48경기씩. 8명은 2코트, 나머지는 3코트. 경기 시간은 시드로 고정한 10~15분 균등 분포다.
- 시드마다 선수 입력 순서를 섞고 가상 시계를 사용한다. 비교하는 두 버전은 같은 로스터·시드·경기 시간 난수열을 사용한다.
- 경기 완료 후 판수 증가·대기 시작·그룹 이력을 반영한다. 경기 중 예약은 최대 1명이며 그 사람이 끝나야 새 경기를 시작한다. 예약된 사람은 다른 팀에서 제외한다.
- 늦참 시나리오는 처음 24명, 45분에 4명 추가다. 추가 당시 보정 판수 평균으로 시작한다. 휴식·수동 개입·중도 퇴장·예비팀 사전 대량 구성은 모사하지 않았다.
- 0/8/12/16 강도를 시드 1~40으로 비교한 뒤 12를 선택했다. 강도 16은 16명 모임의 코트 가동률을 약 91.2%→86.0%, 8명 모임은 75.0%→70.0%로 낮춰 채택하지 않았다.
- 선택에 쓰지 않은 시드 10001~10200으로 기존(0)과 보정(12)을 재검증했다. **6조건 × 200시드 × 2버전 = 2,400세션, 115,200경기**다.

과거 동작의 대조군은 `W_NEW_ENCOUNTER=0`이다. 자동편성의 경기 중 상한을 점수 계산 전에 거르는 변경은 새 항이 0일 때 기존 순위와 동등하다. 기존의 다른 점수는 후보 풀 크기에 의존하지 않는다.

## 만남 범위 결과

각 값은 200세션 평균이며 ‘기존 → 보정’ 순이다. ‘하위 10%’는 각 세션의 개인별 고유 동반자 수 10백분위 값을 평균한 것이다. 쌍은 순서를 구분하지 않는다. 변화량의 ±는 같은 시드끼리 뺀 차이의 표준오차(SE)이며 개인별 변화 범위가 아니다.

## 판수·실력·대기와의 절충

판수 표준편차는 늦참 보정을 포함한 값이다. 경기 등급 범위는 4명의 최대−최소, 편 간 차이는 페어 편성 후 두 편의 등급 합 차이다. 대기 p95는 각 세션에서 합류/직전 종료부터 다음 시작까지의 대기시간을 계산한 뒤 95백분위를 구한 평균(분)이다. 마지막 경기 후 종료까지의 대기는 제외한다.

| 조건 | 판수 표준편차 | 경기 등급 범위 | 편 간 등급 합 차이 | 대기 p95(분) | 코트 가동률 |
| --- | --- | --- | --- | --- | --- |
| 24명 · 남12/여12 | 0.406 → 0.429 | 3.42 → 3.82 | 1.20 → 1.32 | 21.88 → 23.60 | 97.8% → 97.3% |
| 24명 · 남18/여6 | 0.514 → 0.512 | 3.44 → 3.83 | 1.27 → 1.37 | 23.22 → 24.44 | 97.6% → 96.7% |
| 24명 · 2/8등급 양분 | 0.409 → 0.378 | 1.07 → 2.53 | 1.01 → 1.96 | 24.26 → 24.19 | 95.4% → 96.1% |
| 16명 · 남12/여4 | 0.541 → 0.539 | 4.08 → 4.17 | 1.36 → 1.40 | 13.92 → 14.92 | 90.8% → 88.3% |
| 28명 · 45분에 4명 늦참 | 0.486 → 0.508 | 3.18 → 3.60 | 1.21 → 1.32 | 26.03 → 27.08 | 97.7% → 97.4% |
| 8명 · 동일 등급 | 0.309 → 0.280 | 0.00 → 0.00 | 0.00 → 0.00 | 15.74 → 15.16 | 74.7% → 76.1% |

판수 표준편차 증가의 최대치는 이번 비교에서 약 0.024판이었다. 실력별 집단을 넘나드는 만남을 늘리므로 경기의 실력 범위가 넓어진다. 특히 2/8등급으로 양분된 모임에서 편 간 등급 합 차이는 1.01→1.96으로 커졌다. 페어 균형 계산을 유지해도 모든 경기를 같은 품질로 만들 수 있다는 뜻은 아니다.

검증 전에 정한 평균값 기준은 ‘미만남 쌍 증가 없음, 판수 표준편차 증가 ≤0.12판, 대기 p95 증가 ≤2.5분, 가동률 감소 ≤4%p, 편 간 등급 합 차이 증가 ≤1.1’이었다. 6조건 모두 통과했다. 이는 이 시뮬레이션의 수용 기준이며 개별 운영 경기의 보장은 아니다.

관련 회귀 검사 21개 파일·319개 테스트가 통과했으며, 변경 TypeScript/TSX 파일의 ESLint와 `pnpm run build`도 통과했다. 빌드는 기존 청크 크기·정적/동적 import 중복 경고를 남겼다. 앱 배포는 수행하지 않았다.

분석용 예전 시뮬레이션과 운영 실측은 [경기로그 분석 런북](MATCH_LOG_ANALYSIS.md)에 별도로 기록되어 있다. 이번 합성 실험을 실제 사용자의 개선 비율로 해석하지 않는다. 수동으로 정한 조합에는 추천 선택의 효과가 적용되지 않으며, 지난 모임까지 기억하는 기능도 이번 변경에 포함되지 않는다.
