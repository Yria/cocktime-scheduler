# 팀 생성 알고리즘 규칙

## 개요

4명으로 한 **팀**을 구성하고, 팀 내에서 두 **페어**(2v2)로 편성하는 알고리즘. 아래 규칙을 **단계 순서**대로 적용한다.

### 용어 정의
- **팀**: 한 코트에서 경기하는 4명 전체
- **페어**: 팀 안에서 같은 편인 2명 (복식 파트너)

### 데이터 참조 방식 (중요)

`GeneratedTeam.teamA/B`는 `[string, string]` 형태의 **`session_players.id` 참조**다.
`ActiveMatch.teamA/B`도 동일하게 ID 참조다.

알고리즘 내부에서 `SessionPlayer` 객체로 계산하되, 최종 반환 시에는 `.id`만 추출한다.
이를 통해 스킬/성별 변경이 candidateTeams/matchQueue에 즉시 반영되며, 객체 스냅샷 문제가 발생하지 않는다.

## 1단계 — 대기열 구성

### 규칙 1 — 휴식 선수 제외
- 휴식 상태인 선수는 자동 매칭 대상에서 **완전히 제외**한다.
- 대기열은 대기 상태인 선수로만 구성된다.

### 규칙 2 — 전체 경기 횟수 균등 분배 (최우선 선발 기준)
- 모든 선수의 경기 횟수가 비슷하도록, **경기를 적게 한 선수를 먼저 선발**한다.
- 매칭 시작 전 대기열 전체를 경기 횟수 오름차순으로 정렬한다.
- 동점(경기수 같음)이면 기존 대기 순서 유지 (stable sort).

## 2단계 — 팀 선발 (selectFour)

### 규칙 3 — 혼복 우선배치 강제 적용
- 관리자가 혼복 우선배치 플래그를 설정한 선수는 다음 자동 매칭 시 혼복 구성에 **강제 포함**된다.
- 대기 상태인 선수에게만 설정 가능하며, 여러 선수에게 동시에 설정 가능.
- 혼복 우선배치 선수가 존재하면 일반 혼복 조건(여자 ≥ 2 + 남자 ≥ 2)을 충족하지 않더라도 혼복 구성을 우선 시도한다.
- 코트 배정이 완료되는 시점에 플래그 자동 해제.

### 규칙 4 — 혼복 우선, 남자 혼복 균등 참여
- 대기열에 여자 2명 이상 + 남자 2명 이상이 있으면 **혼복(여+남 vs 여+남)을 최우선** 구성한다.
- 남자 선수 중 **혼복 출전이 적은 선수를 우선** 선발하여, 모든 남자가 골고루 혼복을 경험하도록 한다.

### 규칙 5 — 직전 경기 혼복 참여자 배제
- 직전 경기에서 혼복에 출전한 선수(남·여 모두)는 **다음 경기의 혼복 편성에서 최대한 배제**한다.
- 남자: 직전 경기 혼복 출전자는 혼복 선발 우선순위 최하위.
- 여자: 직전 경기 혼복 출전 여자는 혼복 후보에서 후순위 처리.
- 단, 가용 선수가 부족하여 조건을 충족할 수 없는 경우에는 이 규칙을 완화 적용한다.

### 규칙 6 — 혼복 남자 실력 유사성
- 혼복에 투입할 남자 2명은 **서로 실력이 비슷한 쌍**을 선택한다.
- 단, 특정 실력 점수를 가진 선수가 완벽히 일치하는 파트너를 찾지 못해 혼복에서 계속 소외되는 현상을 방지하기 위해, **혼복 출전 횟수(mixedCount) 합산과 실력 차이를 종합적으로 고려**하여 선발한다.
- 점수: `score = (A.mixedCount + B.mixedCount) * 10 + |skill(A) - skill(B)|`
- 혼복 출전 횟수 합산에 큰 가중치(10)를 두어, 횟수가 적은 선수가 무조건 우선적으로 혼복에 참여할 수 있도록 보장한다.

### 규칙 7 — 혼복 여자 실력 유사성
- 혼복에 투입할 여자 2명도 **서로 실력이 비슷한 쌍**을 우선 선택한다.
- 직전 혼복 출전자(규칙 5) 후순위 처리 후, 남은 후보 중 실력 차이가 가장 작은 쌍 선택.
- 예시: 여자 A·B(스킬 전부 X)와 C(스킬 일부 X)가 있으면 A+B를 우선 선발하고, C는 다음 게임에서 규칙 2(경기 횟수 균등)에 의해 자동으로 선발 우선순위가 높아진다.

### 규칙 8 — 여자복식(여복) fallback
- 혼복·남복 구성을 시도했지만 **성별 조건을 충족할 수 없을 때** 여자 4명으로 여복을 구성한다.
- 발동 조건: 대기열에 남자가 부족하거나, 혼복·남복 조건에 맞는 조합이 나오지 않는 경우.
- 선발 방식: 규칙 2(경기 횟수 균등)에 따라 gameCount가 낮은 여자 순으로 팀(4명)을 선발한다.
- 구성 우선순위: 혼복 > 남복 > **여복**(fallback).

### 규칙 9 — 직전 팀 재편성 회피
- 직전 게임에서 같은 팀이었던 선수끼리는 다음 팀에 **함께 배치되지 않도록 최대한 회피**한다.
- 각 선수의 직전 팀 동반자(나머지 3명)를 기록하고, `selectFour`에서 팀을 선발할 때 직전 동반자끼리 겹치는 조합에 페널티를 부여한다.
- **적용 범위**: 모든 게임 타입(남복·여복·혼복·혼합)에 공통 적용. 게임 타입에 무관하게 동작한다.
- **규칙 5와의 관계**: 규칙 5는 "다음 게임에서 혼복을 또 뛰는지"(게임 타입 배정)를 통제하고, 규칙 9는 "누구와 같은 팀이 되는지"(팀 선발)를 통제한다. 두 규칙은 순차적으로 동작하며 서로 간섭하지 않는다. 예: 직전 혼복 출전자 A는 규칙 5에 의해 다음 혼복에서 후순위가 되고, 규칙 9에 의해 직전 동반자 B·C·D를 피한 다른 3명과 팀을 이룬다.
- **데이터**: `lastCoPlayers: Record<string, string[]>` — 각 선수 ID → 직전 게임에서 같은 팀이었던 선수 ID 목록(최대 3명). 코트 배정 완료 시 갱신.
- **완화 조건**: 가용 선수가 부족하여 회피가 불가능한 경우에는 이 규칙을 완화 적용한다.
- **우선순위**: 규칙 2(경기 횟수 균등), 성별 구성 규칙(규칙 4)을 먼저 만족한 뒤 적용한다. 즉, 경기 횟수 균등과 성별 조건이 우선이고, 그 안에서 직전 팀 재편성 회피를 시도한다.

### 대기열 선발 우선순위 요약

1. 규칙 3 해당 선수 존재 시 → 혼복 팀 강제 시도
2. 여자 ≥ 2명 + 남자 ≥ 2명 → 혼복 팀 (규칙 4·5·6·7 적용)
3. 여자 = 1명 + 해당 여자가 혼복허용 여성 목록에 없음 + 남자 ≥ 4명 → 남복 팀 (남자 4명)
4. 상위 혼복·남복 규칙으로 편성 불가 + 여자 ≥ 4명 → 여복 팀 (여자 4명, 규칙 8)
5. 나머지 → 대기 순서대로 팀 구성 (4명)

위 각 단계에서 후보가 4명 이상일 때, 규칙 9(직전 팀 재편성 회피)를 적용하여 직전 팀 동반자끼리 겹치는 조합을 최대한 피한다.

## 3단계 — 페어 편성 (pairingScore)

### 규칙 10 — 페어 내 실력 유사성 (주요 기준)
- 같은 페어의 파트너끼리 실력이 비슷할수록 좋다.
- 점수: `intraDiff = |skill(A1) - skill(A2)| + |skill(B1) - skill(B2)|`
- **낮을수록 좋음** — 가중치 1.5배 적용.

### 규칙 11 — 페어 간 실력 균형 (강약 교차 매칭)
- 강자 2명 + 약자 2명이 선발되면 **[강,약] vs [강,약]**으로 매칭한다. [강,강] vs [약,약]이 되지 않도록 페어 간 실력 합 차이를 최소화한다.
- 점수: `interDiff = |(skill(A1)+skill(A2)) - (skill(B1)+skill(B2))|`
- **낮을수록 좋음** — 가중치 0.5배 적용 (규칙 10보다 낮은 우선순위).

### 종합 점수 공식

```
score = intraDiff × 1.5 + interDiff × 0.5
```

- **점수가 낮을수록 좋은 페어 편성**
- 3가지 가능한 페어 조합 중 score 최솟값 선택

### 혼복 페어 편성

- 각 페어는 반드시 여자 1 + 남자 1로 구성
- 여자와 남자의 매칭은 **스킬 균형**으로 최적 조합 선택

## 4단계 — 다전략 후보 생성 (generateBulkTeamCandidates)

팀 후보를 여러 개 생성할 때, 각 후보마다 **다른 전략**으로 4명을 선발하여 사용자에게 다양한 선택지를 제공한다. 각 전략은 전체 대기열에서 독립적으로 최적의 4명을 탐색한다.

### 전략 목록

| 순서 | 전략 ID | 이름 | 선발 기준 |
|------|---------|------|-----------|
| 1 | `gameCountBalanced` | 게임수 균등 | 기존 `selectFour` 로직 (gameCount 오름차순, 혼복 우선 등 규칙 2~9 적용) |
| 2 | `coPlayerAvoidance` | 동반자 회피 | 전체 대기열에서 `lastCoPlayers` 겹침이 최소인 4명 조합 탐색 |
| 3 | `newCombination` | 새 조합 우선 | `pairHistory` 기반, 과거에 같이 한 적이 가장 적은 4명 조합 탐색 |
| 4 | `mixedCountBalanced` | 혼복 참여 균등 | `mixedCount`가 가장 적은 남자를 강제 포함하여 혼복 편성 (혼복 불가 시 스킵) |
| 5 | `skillBalanced` | 실력 균형 최적 | 4명의 `skillScore` 분산(max-min)이 최소인 조합 탐색 |
| 6 | `randomShuffle` | 랜덤 셔플 | Fisher-Yates 셔플 후 상위 4명 (의외의 조합 발견용) |

### 동작 방식

- `targetCount`(기본 5)만큼 전략 순서대로 후보를 생성한다.
- 동일 4명 중복(seenGroups)이 발생하면 랜덤 셔플로 대체한다.
- 전략이 실패(인원 부족 등)하면 랜덤 셔플로 대체한다.
- targetCount가 전략 수(6)를 초과하면 나머지는 랜덤 셔플로 채운다.

### 선수 다양성 보장

- 후보 간 선수 중복을 최소화하기 위해, 이미 뽑힌 선수를 `usedPlayerIds`로 추적한다.
- 각 전략 실행 전 아직 뽑히지 않은 선수만으로 풀을 구성(unused pool)하여 우선 시도한다.
- unused pool이 4명 미만이면 전체 풀로 폴백한다.
- 이를 통해 하나의 후보를 코트에 배정해도 나머지 후보들이 유효하게 남을 확률이 높아진다.

### 보충 모드 (supplement)

- 기존 유효 후보를 유지하고, 부족분(5 - 유효 수)만 새로 생성하는 모드.
- `existingCandidates` 파라미터로 기존 후보를 전달하면, 해당 후보의 선수와 그룹을 미리 추적하여 중복을 방지한다.

### 후보 생성 흐름

1. **대기 인원으로 팀 생성** — 대기 명단 4명 이상 시 최대 5개 후보 생성
2. **코트 배정 시** — 배정된 선수가 대기에서 빠짐 → 무효 후보 자동 필터링 → 부족분 보충 생성
3. **경기 종료 시** — 선수가 대기로 복귀 → 기존 유효 후보 유지 + 부족분 보충 생성
4. **1번으로 반복**

### 크로스 클라이언트 동기화

- 후보 생성/보충 시 DB(`team_candidates`)에 저장 + `candidates_updated` 브로드캐스트.
- 다른 클라이언트는 브로드캐스트 수신 시 후보 목록을 즉시 교체.
- 늦게 접속한 클라이언트는 DB 스냅샷에서 후보를 로드.

## 공통 규칙

### 규칙 12 — 동점 시 랜덤 선택 (다양성 확보)
- 페어를 편성할 때 점수(실력 차이, 혼복 참여 횟수, 페어링 점수 등)가 완전히 동일한 최적의 조합이 여러 개 발생할 수 있다.
- 이 경우 항상 같은 순서의 선수가 선택되는 것을 방지하기 위해, **동점인 후보군 중에서 무작위(랜덤)로 하나를 선택**한다.
- 이를 통해 매칭 결과의 고착화를 막고, 세션이 진행될수록 더 다양하고 새로운 조합의 경기가 만들어지도록 보장한다.

### 혼복 남자 참여 공정성 원칙

#### 문제 배경

혼복이 편성될 때 남자 선발 대상이 의도치 않게 줄어드는 상황이 발생할 수 있다. 대기열을 경기 횟수 순으로 정렬하면, 경기 횟수가 적은 여자 선수들이 상위권을 점유한다. 그 결과 같은 경기 횟수를 가진 남자들이 밀려나 혼복 선발 대상 자체에서 빠지게 된다.

**예시** (여자 5명 + 남자 13명):
- 여자들의 경기 횟수가 낮으면 정렬 상위권을 여자가 대거 점유
- 그 틈에 끼어든 소수의 남자들만 혼복 선발 대상이 됨
- 혼복 남자 선발 규칙(mixedCount 우선)이 이 소수 안에서만 작동
- 결과적으로 특정 남자는 세션 내내 혼복에 출전하지 못함

#### 원칙

**경기 횟수 균등(규칙 2)과 혼복 횟수 균등(규칙 4)은 독립적으로 작동해야 한다.**

- 어떤 선수가 이번 경기에 출전하는지(규칙 2)와 혼복이 편성될 때 남자를 누구로 선발하는지(규칙 4·6)는 서로 간섭해서는 안 된다.
- 혼복 여부 판단과 여자 2명 선발은 규칙 2에 의해 우선순위가 결정된 선발 대상 안에서 이루어진다.
- 혼복 남자 2명 선발은 **대기 중인 남자 전원**을 대상으로 규칙 4·5·6을 적용한다.

#### 단계별 선발 대상 범위
