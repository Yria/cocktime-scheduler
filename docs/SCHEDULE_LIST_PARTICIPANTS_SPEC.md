# 일정목록 · 참여자 화면 기획

## 1. 목적과 전제

- **일정목록**: 로그인한 회원이 클럽의 예정 일정을 한눈에 보고, 참석/취소·게스트·카풀·늦참을 그 자리에서 처리하는 홈 화면.
- **참여자**: 특정 일정의 참석 명단 전체를 확인하는 화면(운영진은 명단 관리도 가능).
- **전제**: 열람은 로그인 필수. 비로그인 사용자에게는 로그인 화면만 노출한다.

---

## 2. 일정목록 화면

### 2.1 화면 구성
- 상단: 로고 / 알림 / 메뉴(프로필 편집 등)
- **진행 중 세션 이어하기**: 지금 운영 중인 경기 세션이 있으면 최상단에 바로가기 노출
- **일정 리스트**: 예정 일정을 카드로 나열
- 운영진 전용 진입점: `일정 관리`(일정 생성·반복규칙 관리), `즉석 세션 시작`
- 하단: 매치 로그 보기

### 2.2 목록에 보이는 일정 / 정렬 규칙
- **종료된 일정은 숨긴다.** 모집 상태인데 종료 시각이 지난 일정은 목록에서 사라진다. 단, 실제 경기가 진행 중인 일정은 종료 시각과 무관하게 계속 보인다.
- **시작 시각이 지난 모집 일정은 최상단으로 올리고 강조**한다(“곧/지금 시작” 신호).
- 그 외 일정은 그 아래에 이어서 표시.

### 2.3 일정 카드에 담기는 정보
- 날짜·시간(시작~종료), 장소(없으면 “장소 미정”)
- 배지: **진행중**(경기 시작됨), **정모**(정기모임 회차)
- **참석 현황 요약**: 확정 N/정원 · 대기 N · 늦참 N · 🍚 N(식사 체크 회차만). 정원을 넘겨 확정된 사람이 있으면 확정 수 뒤에 사유별로 덧붙인다 — “(운영진 2명)”, “(운영진 2 · 신규 3)”. 이때 확정 N 은 정원보다 클 수 있다.
- 참가자 아바타 미리보기(최대 6명, 초과분은 +N) → 탭하면 참여자 화면으로
- 정모 회차는 **대진표·안내 보기** 진입 버튼 제공 — **본문(대진표)이 실제로 작성된 회차에만**. 비어 있으면 눌러도 “준비 중”만 나와 헛걸음이므로 버튼 자체를 띄우지 않는다.
- 식사 체크 회차는 **회식 가게**를 표시(참석 여부와 무관하게 노출 — 어디서 먹는지 알아야 참여를 정한다). 탭하면 모임 장소와 같은 경로로 지도가 열린다(운영진이 카카오 검색으로 고른 좌표가 있으면 핀, 이름만 적었으면 이름 검색).

### 2.4 회원 액션 (카드 내)
- **참석하기 / 참여 취소** — 취소는 재확인 후 실행
- 내 현재 상태를 배지로 표시: **참석 중 / 대기 N번째 / 정원 외 늦참**
- **게스트 신청**: 본인이 참석 중일 때만 가능
- **카풀 의향**: 카풀 사용 일정에서 운전 가능 / 탑승 필요 / 안 함 선택
- **식사 참여**: 정모 + 식사 체크 회차에서 참여 / 안 먹음 선택. **기본은 참여**(안 먹는 사람만 바꾼다) — 그래서 미응답과 참여를 구분하지 않는다. 내가 데려온 게스트 몫도 함께 고른다(게스트는 계정이 없어 스스로 못 고름).
- **늦참 설정**: 시작·종료가 정해진 모집 일정에서 도착 지연 시간을 조절

### 2.5 참석 상태 규칙
- **확정 / 대기 / 정원 외 늦참 / 취소** 4가지.
- 정원이 차면 이후 신청자는 **대기**로 접수되고, 확정자가 빠지면 **자동 승급**된다(승급 순서는 신청 순서 — 아래 신규 회원 예외도 이 순서를 건드리지 않는다).
- **신규 회원은 첫 2주 동안 대기를 건너뛴다.** 가입일부터 2주 안에 열리는 회차는 정원이 다 차 있어도 [참석하기]가 바로 확정으로 접수된다.
  - **대관비를 걷는 일정은 예외** — 정원까지만 받으므로 만석이면 신규 회원도 대기로 접수된다.
  - **인원 제한은 없다** — 유예 중인 신규 회원이 여럿이면 여럿 다 들어온다(운영진 프리패스 2명과는 별개). 유예가 2주뿐이고 한 사람이 한 자리만 만들기 때문에 인원으로 자르지 않는다.
  - **본인이 [참석하기]를 누른 순간에만 적용된다.** 누른 시점에 이미 2명이 찼으면 그 신규 회원은 평범한 대기자가 되어 신청 순서를 지킨다 — 대기 중에 앞 순번을 추월하는 일은 없다.
  - 유예 중인 회원에게는 **앱을 열 때마다 안내 다이얼로그**를 띄운다(유예 마지막 날짜를 함께 알려준다). 미납 알림과 같은 규칙이다 — 닫기는 이번 실행에만 유효하고, 유예가 끝나면 자연히 안 뜬다. 1회만 띄우면 정작 만석 회차를 만난 날엔 안내가 없어 “만석이니 못 가겠네”로 읽고 신청을 포기하기 때문이다.
  - 참석/늦참 재확인 문구에도 “만석이어도 접수될 수 있다”는 한 줄을 덧붙인다. 조건부(대관비 없는 일정)이므로 단정하지 않는다.
  - **진입 알림은 한 번에 하나만 뜬다.** 미납 알림과 이 안내가 동시에 해당되면 미납이 먼저 뜨고, 확인/닫기를 누르면 그 자리에 이 안내가 뜬다(모달이 겹쳐 배경 스크롤락·포커스가 엉키는 것을 막는다).
- **정원 외 늦참**: 일정 후반(늦은 시각) 이후 도착하겠다고 신청하는 경우. 정원과 **별도로** 접수되어 확정 인원 수에 포함되지 않는다. 도착 시 자리가 있으면 참여, 없으면 대기 — 단 프리패스 대상(운영진·신규회원)은 만석이어도 참여로 접수될 수 있다(정시 복귀도 같은 규칙).
  - 정원 외 늦참으로 **진입**할 때는 “정원과 별도 접수됨”을 재확인받는다.
  - 이미 확정 상태에서 늦참으로 전환하고 대기자가 있으면, 내 자리는 대기 1순위에게 넘어간다.

### 2.6 게스트 규칙
- 참석 중인 회원만 게스트를 신청할 수 있다.
- **세션당 확정 게스트는 최대 2명.** 초과분은 대기로 접수되고, 확정 게스트가 빠지면 순서대로 승급된다. 2명이 찬 상태에서 신청하면 “대기로 들어간다”는 안내를 먼저 확인받는다.
- 같은 이름의 실제 회원이 있으면 게스트로 신청 불가(본인이 직접 참석하도록 안내).
- 게스트를 데려온 회원은 자신의 게스트를 직접 취소할 수 있다.

### 2.7 운영진 전용
- **경기 시작**: 모집 일정에서 시작 10분 전부터 노출. 누르면 경기 세션으로 전환.
- **카풀 공지 만들기**: 카풀 의향자가 있을 때 공지 빌더 진입.

## 3. 참여자 화면

### 3.1 성격
- 일정 카드에서 진입하는 명단 화면(바텀시트). 기본은 읽기 전용.

### 3.2 구성
- 헤더: 해당 일정의 시간·장소·참석 현황 요약(확정/대기/늦참, 정원 초과 확정이 있으면 사유별로 “(운영진 2 · 신규 1)”, 식사 체크 회차는 식사 N명)
- 명단을 **네 그룹으로 구분**해서 보여준다: **확정 → 정원 외(프리패스) → 대기 → 정원 외 늦참**
  - **정원 외(프리패스)**: 만석에도 들어온 사람 — 운영진 프리패스, 신규회원 2주 프리패스. 섹션 제목에 사유별 인원을 적는다(“운영진 2명 · 정원 외”, “운영진 2 · 신규 1 · 정원 외”). 정원 안 운영진·신규는 확정 그룹에 그대로 둔다.
- 그룹별 각 참가자 한 줄에:
  - 아바타·이름(본인은 “(나)” 표기)
  - **운영진 표식(왕관)**, **게스트 표식**(누가 데려온 게스트인지 함께 표기), **신규 표식(🌱 신규)** — 가입 2주 이내 회원. 만석에도 들어올 수 있는 이유가 화면에서 보이게 하는 딱지이므로 확정·대기·늦참 어느 그룹에서든 붙는다.
  - 우측 부가정보: **식사 안 함**(식사 체크 회차의 불참자만 — 기본이 참여라 불참이 정보다. 대기 순번·카풀과 배타가 아니라 함께 보인다), **늦참 도착 예정 시각**, **대기 순번** 또는 **카풀 의향**
- 시각적 구분: 대기자는 흐리게, 정원 외 늦참은 별도 강조 링.
- 참가자가 없으면 “아직 참가자가 없습니다”.

### 3.3 운영진 액션
- 각 참가자를 **명단에서 제거**할 수 있다(본인 행 제외 — 본인은 카드의 ‘참여 취소’ 사용).
- 제거 시 재확인하며, 상황에 따라 안내 문구가 달라진다:
  - 확정자 제거 → “확정에서 제외”, 모집 중이면 “대기자 자동 승급” 안내 포함
  - 대기자 제거 → “대기 명단에서 제외”
  - 당사자(또는 게스트 신청 회원)에게 **알림 발송** 여부를 문구로 명시(단, 운영진이 자신이 데려온 게스트를 제거하면 알림 생략).
