# 일정목록 · 참여자 화면 기획

## 1. 목적과 전제

- **일정목록**: 로그인한 회원이 클럽의 예정 일정을 한눈에 보고, 참석/취소·게스트·카풀·늦참을 그 자리에서 처리하는 홈 화면.
- **참여자**: 특정 일정의 참석 명단 전체를 확인하는 화면(운영진은 명단 관리도 가능).
- **전제**: 열람은 로그인 필수. 비로그인 사용자에게는 로그인 화면만 노출한다.

## 2. 일정목록 화면

### 2.1 화면 구성
- 상단: 로고 / 알림 / 메뉴(프로필 편집 등)
- **진행 중 세션 이어하기**: 지금 운영 중인 경기 세션이 있으면 최상단에 바로가기 노출
- **일정 리스트**: 예정 일정을 카드로 나열
- 운영진 전용 진입점: `일정 관리`(일정 생성·반복규칙 관리), `즉석 세션 시작`
- 하단: 매치 로그 보기

### 2.2 목록에 보이는 일정 / 정렬 규칙
- **종료된 일정은 숨긴다.** 모집 상태인데 종료 시각이 지난 일정은 목록에서 사라진다. 단, 실제 경기가 진행 중인 일정은 종료 시각과 무관하게 계속 보인다.
- **시작 시각이 지난 모집 일정은 최상단으로 올리고 강조**한다(“곧/지금 시작” 신호).
- 그 외 일정은 그 아래에 이어서 표시.

### 2.3 일정 카드에 담기는 정보
- 날짜·시간(시작~종료), 장소(없으면 “장소 미정”)
- 배지: **진행중**(경기 시작됨), **정모**(정기모임 회차)
- **참석 현황 요약**: 확정 N/정원 · 대기 N · 늦참 N
- 참가자 아바타 미리보기(최대 6명, 초과분은 +N) → 탭하면 참여자 화면으로
- 정모 회차는 **대진표·안내 보기** 진입 버튼 제공

### 2.4 회원 액션 (카드 내)
- **참석하기 / 참여 취소** — 취소는 재확인 후 실행
- 내 현재 상태를 배지로 표시: **참석 중 / 대기 N번째 / 정원 외 늦참**
- **게스트 신청**: 본인이 참석 중일 때만 가능
- **카풀 의향**: 카풀 사용 일정에서 운전 가능 / 탑승 필요 / 안 함 선택
- **늦참 설정**: 시작·종료가 정해진 모집 일정에서 도착 지연 시간을 조절

### 2.5 참석 상태 규칙
- **확정 / 대기 / 정원 외 늦참 / 취소** 4가지.
- 정원이 차면 이후 신청자는 **대기**로 접수되고, 확정자가 빠지면 **자동 승급**된다.
- **정원 외 늦참**: 일정 후반(늦은 시각) 이후 도착하겠다고 신청하는 경우. 정원과 **별도로** 접수되어 확정 인원 수에 포함되지 않는다. 도착 시 자리가 있으면 참여, 없으면 대기.
  - 정원 외 늦참으로 **진입**할 때는 “정원과 별도 접수됨”을 재확인받는다.
  - 이미 확정 상태에서 늦참으로 전환하고 대기자가 있으면, 내 자리는 대기 1순위에게 넘어간다.

### 2.6 게스트 규칙
- 참석 중인 회원만 게스트를 신청할 수 있다.
- **세션당 확정 게스트는 최대 2명.** 초과분은 대기로 접수되고, 확정 게스트가 빠지면 순서대로 승급된다. 2명이 찬 상태에서 신청하면 “대기로 들어간다”는 안내를 먼저 확인받는다.
- 같은 이름의 실제 회원이 있으면 게스트로 신청 불가(본인이 직접 참석하도록 안내).
- 게스트를 데려온 회원은 자신의 게스트를 직접 취소할 수 있다.

### 2.7 운영진 전용
- **경기 시작**: 모집 일정에서 시작 10분 전부터 노출. 누르면 경기 세션으로 전환.
- **카풀 공지 만들기**: 카풀 의향자가 있을 때 공지 빌더 진입.

## 3. 참여자 화면

### 3.1 성격
- 일정 카드에서 진입하는 명단 화면(바텀시트). 기본은 읽기 전용.

### 3.2 구성
- 헤더: 해당 일정의 시간·장소·참석 현황 요약(확정/대기/늦참)
- 명단을 **세 그룹으로 구분**해서 보여준다: **확정 → 대기 → 정원 외 늦참**
- 그룹별 각 참가자 한 줄에:
  - 아바타·이름(본인은 “(나)” 표기)
  - **운영진 표식(왕관)**, **게스트 표식**(누가 데려온 게스트인지 함께 표기)
  - 우측 부가정보: **늦참 도착 예정 시각**, **대기 순번** 또는 **카풀 의향**
- 시각적 구분: 대기자는 흐리게, 정원 외 늦참은 별도 강조 링.
- 참가자가 없으면 “아직 참가자가 없습니다”.

### 3.3 운영진 액션
- 각 참가자를 **명단에서 제거**할 수 있다(본인 행 제외 — 본인은 카드의 ‘참여 취소’ 사용).
- 제거 시 재확인하며, 상황에 따라 안내 문구가 달라진다:
  - 확정자 제거 → “확정에서 제외”, 모집 중이면 “대기자 자동 승급” 안내 포함
  - 대기자 제거 → “대기 명단에서 제외”
  - 당사자(또는 게스트 신청 회원)에게 **알림 발송** 여부를 문구로 명시(단, 운영진이 자신이 데려온 게스트를 제거하면 알림 생략).
