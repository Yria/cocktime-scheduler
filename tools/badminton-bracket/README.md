# 배드민턴 복식 대진표 생성기

정모(정기모임)용 복식 대진표를 제약 조건을 모두 만족하도록 자동 편성하는 도구.
출력 마크다운을 앱의 **정모 안내 입력란(`sessions.notice_md`)** 에 그대로 붙여넣으면
회원이 `/notice/:sessionId`(RegularNoticePage)에서 스타일된 표로 본다.

> 순수 Python(표준 라이브러리만). `python3 bracket.py` 한 줄로 끝.
> 처음 만든 맥락: 2026-06-30 세션. "나중에 비슷하게 또 할" 용도로 영구 보관.

---

## 1. 문제(대진 규칙)

- **6개 조** A~F, 각 조 5명 = 30명. 조 내 번호 **1·2 = 여자, 3·4·5 = 남자**.
- 모든 경기는 **복식**. 한 경기 = 한 조에서 2명(한 팀) vs 다른 조에서 2명(상대 팀).
- 조 안 페어 10종을 **각 2회씩** 사용. 페어 타입:
  - 여복: {1,2}  · 혼복: {1,3}{1,4}{1,5}{2,3}{2,4}{2,5}  · 남복: {3,4}{3,5}{4,5}
- **여복↔여복 / 혼복↔혼복 / 남복↔남복** 끼리만 대결.
- 결과적으로: **1인당 정확히 8경기**, 각 조는 다른 5개 조와 **각 4경기**, 총 **60경기**.
- 코트 **5개** → **12라운드**. 같은 선수가 한 라운드에 두 코트 동시 출전 금지.

## 2. 추가로 건 공정성 규칙

- **Rule X**: 한 페어의 2회 출전을 **서로 다른 상대 조**에 배정 → 같은 페어가 같은 개인/페어를
  두 번 만나는 일 0건. (페어의 각 인스턴스를 다른 조로 보내면 자동 보장.)
- **개인 재대결 최소화**: "서로 다른 페어를 통해 같은 두 사람이 또 만나는" 경우는
  **완전 제거 불가**(증명 아래) → 담금질로 최소화. 현재 해 **19건**.

### 왜 개인 단위 완전 무중복은 불가능한가 (기존 규칙과 충돌)
"각 페어 2회"가 **여복 6경기를 강제**한다. 두 조 사이 경기를 여복 w·혼복 m·남복 x(=합 4)라 하면
여-여 대결 수 `4w+m`(가능 4쌍뿐), 남-남 `4x+m`(가능 9쌍). 여복이 있는 조쌍(w≥1)은
`4w+m≤4`를 만족하려면 x≥3이 되어 `4x+m>9` → 남-남 중복 강제. 즉 여복+혼복을 같이 치르는
어떤 두 조든 재대결이 불가피. (여-여 재대결 하한 = 사이클 변 6개 × 1 = 6건이 실제 최소.)

## 3. 알고리즘 개요 (`bracket.py`)

1. **조쌍 타입 배분(alloc)**: 6조를 6각형으로 보고
   - cycle 변(인접): 여1·혼1·남2  · diam 변(대각): 여0·혼2·남2  · tri 변(거리2): 여0·혼4·남0
   - 이 배분이 여복 6/혼복 36/남복 18·각 조 합(여2·혼12·남6)을 맞추고 재대결 하한을 낮춤.
2. **라벨 배정(build_matches)**: 각 조의 타입별 슬롯에 페어를 채우되 Rule X(페어→서로 다른 조)
   유지. `assign_constrained` 백트래킹.
3. **담금질(anneal)**: 같은 조·같은 타입 슬롯의 라벨을 교환(Rule X 유지)하며 개인 재대결을
   최소화. 30×30 정수 카운트로 고속.
4. **스케줄(schedule)**: 충돌 그래프 위 균등 그래프 컬러링 백트래킹으로 12라운드×5코트 배치
   (라운드 중복 0).
5. **검증(verify)**: 위 모든 불변식 assert. **HTML/마크다운 출력**.

> 솔루션은 `bracket_sol.pkl`에 캐시. 재실행 시 캐시를 읽어 즉시 출력(담금질 재실행 안 함).
> 알고리즘/인원/규칙을 바꾸면 `rm bracket_sol.pkl` 후 재실행해 새로 풀 것.

## 4. 사용법

```bash
cd tools/badminton-bracket

# 전체 풀이(캐시 없으면 생성) → 검증 통계 + current_bracket.html 생성
python3 bracket.py

# 정모 입력란용 마크다운(조편성 + 라운드별 표) 생성 → current_bracket.md / stdout
python3 gen_md.py
```

- `gen_md.py` 출력(또는 `current_bracket.md`)을 복사 → 앱에서 **일정(정모) 토글 ON →
  안내·대진표 입력란**에 붙여넣기.
- `current_bracket.html`은 인쇄·열람용 단일 페이지(Artifact로 게시했던 그 페이지).

## 5. 편집 레시피

### (A) 특정 경기를 원하는 페어로 고정하고 전체 재최적화 — `opt_pinned.py`
예: "R10 코트4를 심유진·김길환 vs 송수민·김태혁으로". C-D 혼복은 규칙상 1경기뿐이라
그 슬롯을 C{1,3} vs D{1,4}로 고정한 뒤 나머지를 다시 담금질(재대결 19 유지).
다른 칸을 고정하려면 `opt_pinned.py`의 `forced`(C/D 라벨)·`TARGET`·`PIN_ROUND`를 수정.
실행 전 `rm bracket_sol.pkl`(새로 풀어 캐시 갱신).

### (B) 딱 한 칸만 바꾸기(최소 변경) — 라벨 스왑
"각 페어 2회" 때문에 한 칸만 못 바꾼다. 바꾸려는 페어와 **같은 페어를 쓰는 다른 경기**를
찾아 라벨을 맞교환(swap)하면 인원수·조경기수·타입이 자동 보존된다. Rule X와 라운드 중복만
재검증하면 됨(개인 재대결이 소폭 늘 수 있음). 패턴 예시는 이 도구의 git 히스토리(edit 스크립트) 참고.

### (C) 연속 출전 줄이기(라운드 재배치) — `reschedule.py`
"특정 선수가 너무 연속으로 뛴다"류 요청. **경기 조합은 그대로 두고 라운드 배치만** 담금질로
재편성 → 페어/조쌍/타입/Rule X/재대결이 전부 보존되고 개인 연속 출전만 줄어든다.
- 이동 = **두 경기의 라운드 맞교환**(항상 5경기/라운드 유지). 일시적 중복출전은 벌점(BIG)으로 허용해
  담금질이 통과. 최종은 중복 0인 상태 중 연속벌점 최소를 채택.
- 연속 벌점 = 각 연속 run 길이 s에 대해 `(s-2)^2`(2연속까지 무벌점). 특정 선수는 `WEIGHT`로 가중.
- 실행: `python3 reschedule.py`(캐시의 color만 갱신) → `bracket.py`·`gen_md.py` 재실행.
- 주의: R10 고정칸은 라운드10에 유지되도록 `pin_idx`를 이동에서 제외. 단순 1경기 이동은 균형이 깨져
  전부 거부되므로 **반드시 swap 이동**을 쓸 것(초기 시도 실패 교훈).

## 6. 인원·규모를 바꾸려면

- 이름/조 구성: `bracket.py` 상단 `NAMES`(그리고 필요시 `GROUPS`).
- 6조·5명·5코트가 아닌 구성으로 바꾸면 `ALLOC_BY_TYPE`·슬롯 수·`schedule`의 라운드/코트 수를
  다시 설계해야 함(현재 수치는 30명·6조 전용으로 손계산된 값).

### 연속 출전 한계 (2026-07-01 조사)
- **전역 "최대 3연속"은 사실상 불가.** 현재 조합 재배치는 4연속 9~12명에서 정체, 팀 재구성 탐색도 실패.
  근본 이유: 라운드당 20명 출전이라 **인접 두 라운드가 반드시 ≥10명 공유** → 복식·5코트·30명에서
  전원 ≤3연속을 동시에 못 맞춤. **max-4가 실용적 하한**(5연속 이상은 0으로 만들 수 있음).
- 특정 1~2명만 ≤3으로 강제하면 그 부담이 남에게 쏠려 **다른 사람이 5~6연속**이 됨(전역 악화).
  → 개인 보호보다 "전역 5연속 금지 + 최대 4"가 균형점. `reschedule.py`의 `pen_player`로 가중 조절 가능.
